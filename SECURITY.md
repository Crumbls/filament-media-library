# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of Filament Media
Library. Please upgrade to the most recent release before reporting an issue.

## Reporting a Vulnerability

Please report vulnerabilities privately through [GitHub Security
Advisories](https://github.com/Crumbls/filament-media-library/security/advisories/new).
If private reporting is unavailable, email [chase@crumbls.com](mailto:chase@crumbls.com)
with the subject `Security vulnerability: filament-media-library`.

Include the affected version, a clear description of the issue, steps to
reproduce it, and any suggested mitigation. We will acknowledge reports within
seven days and work with you on disclosure after a fix is available.
